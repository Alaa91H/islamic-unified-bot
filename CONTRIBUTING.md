# Contributing to Islamic Unified Bot

Thanks for considering a contribution.

## Before you start
- Search existing issues and pull requests.
- Discuss substantial behavior or architecture changes in an issue first.
- Report vulnerabilities privately as described in [SECURITY.md](SECURITY.md).
- Never commit credentials, signing keys, tokens, private logs, or personal data.

## Workflow
1. Create a focused branch.
2. Make the smallest change that fully solves the problem.
3. Follow the existing architecture, naming, and formatting.
4. Update tests and documentation when behavior changes.
5. Run the checks documented by the repository and CI.
6. Open a pull request explaining the problem, solution, and verification.

Keep pull requests focused, document compatibility impact, include screenshots for meaningful UI changes, and avoid unrelated refactors or generated-file churn.
